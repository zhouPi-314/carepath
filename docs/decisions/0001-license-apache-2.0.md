# ADR-0001：开源许可证决策

- 状态：**已确认（2026-10-22）**
- 决策人：项目所有者
- 结论：采用 **Apache License 2.0**。

## 背景

项目所有者确认在 Apache-2.0 与 MIT 之间均可接受。交接文档建议：若希望包含明确专利授权、降低协作中的专利风险，优先 Apache-2.0；若只需最简宽松许可，可选 MIT。

## 决策

采用 Apache-2.0，理由：

1. 包含明确的专利授权条款，适合后续与医院、企业或研究机构协作。
2. 与仓库内已参考的开源项目（Apache-2.0 / MPL-2.0）兼容路径更清晰。
3. 保留 NOTICE 机制，便于记录归属。

## 影响

- 仓库根目录新增标准 `LICENSE` 文本（Apache License 2.0，逐字采用官方文本）。
- README、CHANGELOG、CONTRIBUTING 同步声明。
- 贡献默认按 Apache-2.0 授权；如需 DCO/CLA 另行约定。
- 若项目所有者后续更倾向 MIT，可替换 `LICENSE` 并同步本记录；已发布版本的历史许可不追溯变更。
