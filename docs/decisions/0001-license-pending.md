# ADR-0001：开源许可证决策（待确认）

- 状态：**待项目所有者确认**
- 日期：2026-10-22

## 结论

仓库目前**未选定许可证**。在没有明确许可证的情况下，公开仓库默认保留全部权利，不构成有效的开源授权。正式发布前必须由项目所有者确认；确认前不在仓库中加入正式 `LICENSE` 文本，避免误示。

## 候选与建议

| 许可证 | 适用场景 | 备注 |
|---|---|---|
| Apache-2.0（建议） | 协作开发、专利授权明确 | 适合希望降低专利风险的开源协作 |
| MIT | 最小文本、宽松使用 | 无明确专利授权条款 |
| GPL/AGPL | 传染性义务较重 | 与已参考项目代码混用会增加义务，不作为默认路径 |

## 影响

- 未确认前不得宣称仓库已是法律意义上的开源项目。
- `CHANGELOG.md` 与 `README.md` 的“开源状态”部分保持一致。
- 项目所有者确认后：添加对应 `LICENSE` 文件、更新 README 与 CHANGELOG，并可在首次 release 时正式声明。
