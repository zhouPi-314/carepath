# 角色与治疗协同流程

平台按五类入驻主体组织服务：医院、社区与志愿组织、药企、政府、用户（病患/家属）。登录页只区分入口，病患与家属由医院登记的关系数据标识。

## 1. 医院

- **职工管理**：医院管理员录入本院医生与管理人员，账号归属当前医院。
- **患者标记**：医生或管理员为患者设置照护等级与标签（如慢病、可自理、随访中）。
- **治疗记录**：医生从模板创建计划，写入进展、评估与随访记录；本院其他医生可按患者调取记录，便于连续诊疗。
- **分级转入**：支持医院—康复机构—社区之间的转入登记（转出机构、转入机构、层级、原因、状态）。
- **患者沟通**：医生与病患/家属在计划内留言，记录进入审计。

## 2. 社区与志愿组织

- 维护志愿者名册、技能与联系方式（脱敏）。
- 创建社区随访、生活支持与药品配送任务，指派志愿者。
- 查看药品配送单，与药企供应反馈衔接。
- 仅能访问本组织数据，不可读取医院临床记录。

## 3. 药企

- 维护自有药品目录与批准文号。
- 查看达到发布阈值的区域需求信号（≥3 家机构、≥50 患者月）。
- 提交区域月度产能反馈，供社区配送与供应协同参考。

## 4. 政府

- 机构入驻认证：审核医院、社区组织、药企等主体资料并标记认证状态。
- 区域脱敏聚合：活跃计划少于 10 的区域整体抑制，不含患者标识。
- 平台内审核案件处理，决策写入审计。

## 5. 用户（病患 / 家属）

- **病患**：查看治疗计划、完成任务、记录观察、查看提醒，并在计划内与医生持续沟通。
- **家属**：登录后由医院授权数据标识为家属，按字段与有效期查看进展、代办任务；授权撤销后立即失效。
- 登录页不区分病患与家属，顶部身份徽标显示当前身份。

## 6. 状态与审计

- 计划：草稿 → 待患者确认 → 活跃 → 暂停/完成/取消。
- 任务：待完成 → 进行中 → 已完成/跳过。
- 转入：待接收 → 已完成/拒绝。
- 临床写入、授权变更、转入、审核与导入均写入审计事件。
