# v0.1.0 发布说明

- 版本：**0.1.0**
- 日期：2026-10-23
- 状态：开源平台，合成数据，仅供教学、工程演示与后续试点评估。

## 1. 范围

本版本覆盖患者、家属、医生、医院、政府监管和药企六类业务角色，以及系统管理员的官方数据导入。后端为 Python 模块化单体，Web、Android、微信小程序共享同一套 API 契约。

**非目标**：不提供诊断或治疗建议，不处理真实处方、医保结算或行政处置，不接入真实患者数据或生产外部系统。

## 2. 安装

### 后端（SQLite 演示）

```powershell
cd backend
py -3.13 -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
.\.venv\Scripts\python -m carepath.seed
.\.venv\Scripts\uvicorn carepath.main:app --reload --port 8000
```

健康检查：`GET http://127.0.0.1:8000/health` 返回 `{"status":"ok","service":"carepath-api","version":"0.1.0"}`。

### Web

```powershell
cd apps/web
corepack enable
pnpm install
pnpm dev
```

### 微信小程序

用微信开发者工具打开 `apps/wechat`，AppID 为 `touristappid`（沙箱）。无 AppID 时不能登录真实微信、订阅消息或上线。

### Android

```powershell
.\scripts\build-android.ps1
```

或手动构建：

```powershell
cd apps/android
.\gradlew.bat :app:assembleDebug    # Windows
./gradlew :app:assembleDebug        # macOS / Linux
```

正式命名的构建产物：`TreatmentPlanCoordinationPlatform-v0.1.0-debug.apk`（CI 作为 artifact 上传）。

### Docker Compose

```powershell
Copy-Item .env.example .env
docker compose -f ops/docker-compose.yml up --build -d
```

Web：<http://localhost:8080>；API：<http://localhost:8000>；MinIO 控制台：<http://localhost:9001>。

## 3. 配置

| 变量 | 默认值 | 说明 |
|---|---|---|
| `APP_ENV` | `development` | `production` 时强制 PostgreSQL、显式密钥和安全 Cookie |
| `DATABASE_URL` | `sqlite+aiosqlite:///./carepath.db` | 演示用 SQLite；生产用 PostgreSQL |
| `SECRET_KEY` | 开发占位值 | 生产必须替换为随机密钥 |
| `COOKIE_SECURE` | `false` | 生产必须为 `true`（HTTPS） |
| `CORS_ORIGINS` | 本地 5173 | 逗号分隔的允许来源 |

- 合成病例与演示机构、药品、任务数据（`backend/src/carepath/seed.py`）。

## 7. 已知限制

- 微信开发者工具自动预览未执行，需人工打开沙箱；当前无 AppID，不能真实登录或推送。
- 本机 Windows 中文路径下 JUnit 进程受限，使用 `scripts\test-android.ps1`（ASCII 盘符映射）或 Linux CI。
- 未接入真实 HIS、医保、政务或供应链；相关端口是预留契约，官方公开数据通过人工快照导入。
- Docker 镜像拉取在受限网络下需要配置 registry mirrors；详见故障排查。
- 本版本不等同于完成等保、PIPL 评估、互联网医院准入或医保对接。
